Features

A messaging app for agents.
Everything stays on your machine.

Bring your own engines

Bots run on CLIs you already have, with your own logins and subscriptions. No new account and no proxy.

Rooms with Auto routing

A fast decision model picks which bot answers. If it’s unsure or slow, the room lead takes the message.

Approvals, inline

Shell commands, file edits and questions show up as Allow and Deny cards. Secrets are write-only.

A computer for each bot

A cloud desktop, an isolated local VM, or, if you opt in, this computer.

Memory you can undo

Each bot keeps a workspace with MEMORY.md. You can roll back any memory change.

Routines & webhooks

Scheduled runs and webhook triggers. Export a whole team, and history and keys stay behind.

Run it

Up and running in three commands.

1

Get Node 24 and pnpm

Run corepack enable to get the pinned pnpm.

2

Sign in to one agent CLI

Use claude, codex, or any supported engine. It shows up in the model picker.

3

Start the server and the UI

The harness runs on loopback only. Pair your phone with a short code.

Open Aster Read the guide
~/ASTER — zsh
# install
$ pnpm install --frozen-lockfile

# agent harness → 127.0.0.1:8799
$ pnpm dev:server
server on http://127.0.0.1:8799

# web UI → 127.0.0.1:5199
$ pnpm dev
➜  Local:   http://127.0.0.1:5199/

Aster binds to 127.0.0.1 by default. To reach it from other devices, use Tailscale or your own HTTPS reverse proxy. Never expose the server port directly.
